## 1. RESUMEN DEL PROYECTO

Lancher Electron para GTA V que permite:
- Inyectar mods DLL en GTA V Enhanced y GTA Legacy
- Descargar scripts desde GitHub (.lua, .zip, .rar)
- Inyectar DLLs externas
- Auto-update del launcher
- UI tactica con tema oscuro/naranja
- Encriptacion AES-256-CBC de los mods .enc
- Single instance lock
- Proteccion con contextIsolation y sandbox
- NSIS installer con pagina de fin custom

## 5. SISTEMA DE ENCRIPTACION

### Algoritmo
- AES-256-CBC (legacy v1) / AES-256-GCM (v2)
- Key derivation: SHA-256 de 'RTX2026-GTA5-LAUNCHER-SECURE-ENCRYPT-KEY'
- IV: 16 bytes random (para CBC) o 12 bytes random (para GCM)
- Format v1: [iv(16)][ciphertext] (PKCS7 padding)
- Format v2: [version(1)=0x01][salt(16)][nonce(12)][tag(16)][ciphertext] (GCM)
- Key derivation for v2: scryptSync(passphrase, salt, 32, {N: 16384, r: 8, p: 1})

### Encriptar un DLL nuevo (COMANDO)
```javascript
const crypto = require('crypto');
const ENC_KEY = crypto.createHash('sha256').update('RTX2026-GTA5-LAUNCHER-SECURE-ENCRYPT-KEY').digest();
const data = fs.readFileSync('archivo.dll');
const iv = crypto.randomBytes(16);
const cipher = crypto.createCipheriv('aes-256-cbc', ENC_KEY, iv);
let enc = cipher.update(data);
enc = Buffer.concat([enc, cipher.final()]);
// NO agregar PKCS7 manual - cipher.final() ya lo hace
fs.writeFileSync('archivo.enc', Buffer.concat([iv, enc]));
```

### Verificar encriptacion
```javascript
const v = fs.readFileSync('archivo.enc');
const iv = v.slice(0, 16);
const ct = v.slice(16);
const decipher = crypto.createDecipheriv('aes-256-cbc', ENC_KEY, iv);
let dec = Buffer.concat([decipher.update(ct), decipher.final()]);
// Verificar MZ header
console.log('MZ:', dec[0] === 0x4D && dec[1] === 0x5A);
```

## 6. SISTEMA DE MODS

### Estructura de carpetas
```
src/mods/
├── GTA Enhanced/
│   ├── G MENU V2/
│   │   ├── mod.json
│   │   └── YimMenuV2.enc
│   └── G MENU V2 ROJO/
│       ├── mod.json
│       └── YimMenuV2-RojoT.enc
└── GTA Legacy/
    └── legacy_mod/
        ├── mod.json
        └── legacy_mod.enc
```

### Flujo de inyeccion
1. Usuario selecciona mod y GTA
2. `scanMods()` lee carpetas, busca archivos .enc + mod.json
3. `injectDLL(encPath, processId)`:
   a. `decryptFile(encPath)` → escribe DLL temporal
   b. `OpenProcess(PROCESS_ALL_ACCESS, false, pid)`
   c. `VirtualAllocEx` para la ruta DLL
   d. `WriteProcessMemory` con la ruta DLL
   e. `CreateRemoteThread` con `LoadLibraryW`
   f. `WaitForSingleObject` 5000ms
   g. `VirtualFreeEx`, `CloseHandle`
   h. `unlinkSync` del DLL temporal
   i. `app.quit()` despues de 1500ms

- GTA Enhanced → YimMenuV2 (F5 O INSERT) - NIGHTLY badge cyan
- GTA Enhanced → YimMenuV2 ROJO (F5 O INSERT) - badge red
- GTA Legacy → legacy_mod (INSERT) - badge amber

## 7. SISTEMA DE SCRIPTS

### Flow
1. `fetchScripts(gameVersion)` → GitHub API → lista de archivos
2. `installScript(script, gameVersion)` → descarga .lua/.zip/.rar → extrae
3. `uninstallScript(script, gameVersion)` → elimina archivo/carpeta
4. SHA tracking en `.rtx_scripts_meta.json` para deteccion de updates
5. Boton "Recargar" limpia cache y refetch
6. Overlay de notificacion al abrir si hay scripts con updates
