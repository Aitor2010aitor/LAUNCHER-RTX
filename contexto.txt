## SECCION 2: QUE ES CADA ARCHIVO Y PARA QUE SIRVE

### main.js (927 lineas)
**QUE ES:** El procesador principal del launcher. Corre en segundo plano.
**PARA QUE SIRVE:**
- Detecta procesos de GTA V instalados
- Lee los mods encriptados (.enc) del directorio src/mods/
- Desencripta los .enc a .dll en memoria
- Inyecta los DLLs en GTA V usando Win32 API (koffi)
- Gestiona el auto-update desde GitHub
- Gestiona la descarga de scripts desde GitHub
- Permite inyectar DLLs externas
- Limpia DLLs temporales al cerrar
**LO QUE CONTIENE:**
- `deriveKey()` - deriva clave AES desde passphrase con scrypt
- `decryptFile()` - desencripta .enc a .dll
- `getDecryptedDllPath()` - escribe DLL temporal y retorna ruta
- `initWin32()` - carga todas las funciones de kernel32 via koffi
- `getProcesses()` - enumera procesos activos (GTA5.exe, GTA5_Enhanced.exe)
- `scanMods()` - lee carpetas .enc + mod.json y retorna lista de mods
- `injectDLL()` - decrypt→inject→delete→quit
- `initAutoUpdater()` - sistema de auto-update
- `fetch-scripts` handler - descarga scripts de GitHub API
- `install-script` handler - instala scripts localmente
- `uninstall-script` handler - desinstala scripts
- `select-external-dll` handler - abre file picker para DLL externa
- `inject-external-dll` handler - inyecta DLL externa

### preload.js (27 lineas)
**QUE ES:** Puente seguro entre el main process y el renderer (UI).
**PARA QUE SIRVE:** Expone funciones seguras al frontend via contextBridge.
**LO QUE EXPOSE:**
- `getProcesses()`, `scanMods()`, `injectDLL()`, `checkTempDir()`, `openExternal()`
- `getVersion()`, `getLauncherPath()`, `checkForUpdates()`
- `fetchScripts()`, `installScript()`, `uninstallScript()`, `getScriptsPath()`
- `onUpdateChecking`, `onUpdateAvailable`, `onUpdateNotAvailable`, `onUpdateProgress`, `onUpdateDownloaded`, `onUpdateError`
- `minimize()`, `maximize()`, `close()`
- `selectExternalDll()`, `injectExternalDll()`

### package.json (78 lineas, v1.6.0)
**QUE ES:** Configuracion del proyecto Node.js + electron-builder.
**PARA QUE SIRVE:**
- `dependencies`: koffi, adm-zip, electron-updater
- `devDependencies`: electron 28.3.3, electron-builder 25.1.8
- `build`: configuracion del NSIS installer (icono, admin, nsis)

## SECCION 5: COMO CIFRAR UN DLL NUEVO (PASO A PASO COMPLETO)

### REQUISITOS:
- Node.js instalado
- El archivo .dll que quieres cifrar
- Clave secreta: `RTX2026-GTA5-LAUNCHER-SECURE-ENCRYPT-KEY`

### PASO 1: Descargar el DLL
```powershell
Invoke-WebRequest -Uri "URL_DEL_DLL" -OutFile "C:\Users\Admin\Desktop\launcher\launcher\src\mods\GTA Enhanced\G MENU V2\YimMenuV2.dll" -Headers @{"User-Agent"="RTX-Launcher"}
```

### PASO 2: Verificar que es un DLL valido
```powershell
# Debe empezar con MZ (0x4D 0x5A)
$bytes = [System.IO.File]::ReadAllBytes("C:\Users\Admin\Desktop\launcher\launcher\src\mods\GTA Enhanced\G MENU V2\YimMenuV2.dll")
Write-Output ("MZ header: " + ($bytes[0] -eq 0x4D) + ", " + ($bytes[1] -eq 0x5A))
Write-Output ("Size: " + $bytes.Length + " bytes")
```

### PASO 3: Encriptar el DLL
```powershell
node -e "const crypto=require('crypto'),fs=require('fs');const K=crypto.createHash('sha256').update('RTX2026-GTA5-LAUNCHER-SECURE-ENCRYPT-KEY').digest();const d=fs.readFileSync('C:\Users\Admin\Desktop\launcher\launcher\src\mods\GTA Enhanced\G MENU V2\YimMenuV2.dll');const iv=crypto.randomBytes(16);const c=crypto.createCipheriv('aes-256-cbc',K,iv);let e=c.update(d);e=Buffer.concat([e,c.final()]);fs.writeFileSync('C:\Users\Admin\Desktop\launcher\launcher\src\mods\GTA Enhanced\G MENU V2\YimMenuV2.enc',Buffer.concat([iv,e]));console.log('CIFRADO:',fs.statSync('C:\Users\Admin\Desktop\launcher\launcher\src\mods\GTA Enhanced\G MENU V2\YimMenuV2.enc').size,'bytes');"
```

### PASO 4: Verificar que se puede desencriptar
```powershell
node -e "const crypto=require('crypto'),fs=require('fs');const K=crypto.createHash('sha256').update('RTX2026-GTA5-LAUNCHER-SECURE-ENCRYPT-KEY').digest();const v=fs.readFileSync('C:\Users\Admin\Desktop\launcher\launcher\src\mods\GTA Enhanced\G MENU V2\YimMenuV2.enc');const iv=v.slice(0,16),ct=v.slice(16);const dc=crypto.createDecipheriv('aes-256-cbc',K,iv);let r=dc.update(ct);r=Buffer.concat([r,dc.final()]);console.log('VERIFICACION MZ:',r[0]===0x4D&&r[1]===0x5A,'Size:',r.length);"
```

Debe mostrar `VERIFICACION MZ: true`.

### PASO 5: Borrar el DLL sin cifar (IMPORTANTE)
```powershell
Remove-Item "C:\Users\Admin\Desktop\launcher\launcher\src\mods\GTA Enhanced\G MENU V2\YimMenuV2.dll" -Force
```

### REGLAS CRITICAS:
1. **NO AGREGAR PKCS7 MANUAL** - `cipher.final()` YA agrega padding PKCS7
2. Si agregas padding manual = BAD_DECRYPT (error de doble padding)
3. El IV (16 bytes) se antepone al ciphertext
4. Formato .enc = `[iv(16 bytes)][ciphertext]`
5. El .enc debe tener exactamente 16 bytes mas que el .dll original
6. NUNCA dejes el .dll sin cifar en el directorio de mods
7. Verifica siempre con MZ header antes de borrar el .dll

## SECCION 6: COMO DESCIFRAR (COMO LO HACE EL LAUNCHER)

El launcher hace esto en `main.js` con `decryptFile()`:
```javascript
function decryptFile(encPath) {
  const data = fs.readFileSync(encPath);
  // Formato v1: [iv(16)][ciphertext]
  const iv = data.slice(0, 16);
  const ct = data.slice(16);
  // Derivar clave desde passphrase con SHA-256
  const ENC_KEY = crypto.createHash('sha256').update('RTX2026-GTA5-LAUNCHER-SECURE-ENCRYPT-KEY').digest();
  // Desenciptar AES-256-CBC
  const decipher = crypto.createDecipheriv('aes-256-cbc', ENC_KEY, iv);
  decipher.setAutoPadding(false);
  let dec = Buffer.concat([decipher.update(ct), decipher.final()]);
  // Quitar padding PKCS7 (solo UNA vez)
  const padLen = dec[dec.length - 1];
  if (padLen > 0 && padLen <= 16) dec = dec.slice(0, dec.length - padLen);
  return dec;
}
```

## SECCION 7: ALGORITMO DE CIFRADO DETALLADO

### AES-256-CBC
- **Algoritmo:** Advanced Encryption Standard, 256-bit key, Cipher Block Chaining
- **Clave:** SHA-256 hash de `'RTX2026-GTA5-LAUNCHER-SECURE-ENCRYPT-KEY'` = 64 chars hex = 256 bits
- **IV:** 16 bytes aleatorios - diferente cada vez que se cifra
- **Padding:** PKCS7 - rellena para multiplo de 16 bytes
- **Formato .enc:** `[IV(16 bytes)][CIPHERTEXT]`
- **Para que sirve:** Proteger los DLLs para que no sean facilmente analizados

## SECCION 14: PROBLEMAS CONOCIDOS Y SOLUCIONES

### BAD_DECRYPT (FIXEADO en v1.5.3):
- **Causa:** Agregar padding PKCS7 manual despues de `cipher.final()`
- **Solucion:** NO agregar padding manual - `cipher.final()` ya lo hace
- **Verificacion:** Siempre verificar MZ header al desencriptar

### Select-String no funciona en cmd.exe:
- **Solucion:** Usar `findstr` en cmd.exe
- **Opcion alternativa:** Usar PowerShell con `Select-String`

### `&&` no funciona en PowerShell:
- **Solucion:** Usar `;` o `cmd /c` o archivos .bat
- **Ejemplo:** `cmd.exe /c "comando1 & comando2"`

### `|` no funciona en PowerShell dentro de comillas:
- **Solucion:** Usar scripts .bat o .ps1 en archivos separados
