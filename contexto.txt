## 3. STACK TECNICO Y DEPENDENCIAS EXPLICADAS

### Dependencias runtime (package.json dependencies)

**`koffi`: ^2.8.0**
- **Que hace:** Permite llamar funciones de DLLs de Windows (Win32 API) desde JavaScript/Node.js
- **Para que sirve:** Para inyectar DLLs en GTA V - llama a funciones como OpenProcess, VirtualAllocEx, WriteProcessMemory, CreateRemoteThread, LoadLibraryW
- **Alternativa intentada:** `ffi-napi` - NO funciono porque daba error `_Inout_` qualifier con MSVC
- **Como funciona:** Cargas `kernel32.dll` con `koffi.load('kernel32.dll')` y luego llamas funciones con `kernel32.func('NombreFuncion', 'tipo_retorno', ['tipo_param1', 'tipo_param2'])`

**`adm-zip`: ^0.6.1**
- **Que hace:** Permite crear, leer y extraer archivos ZIP desde Node.js sin dependencias externas
- **Para que sirve:** Para extraer archivos .zip que contienen scripts de GTA V
- **Como funciona:** `const zip = new AdmZip(ruta_zip); zip.extractAllTo(destino, true);`

**`electron-updater`: ^6.3.9**
- **Que hace:** Sistema de auto-update que verifica si hay nueva version en GitHub Releases y la descarga
- **Para que sirve:** Cuando el launcher detecta que hay una version nueva disponible, la descarga automaticamente
- **Configuracion:** `autoDownload: true`, `autoInstallOnAppQuit: false` (NO instala automaticamente - pide al usuario), `disableWebInstaller: true`

### DevDependencies

**`electron`: ^28.0.0 (version exacta 28.3.3)**
- **Que hace:** Framework que permite crear aplicaciones de escritorio con HTML/CSS/JS
- **Version especifica:** 28.3.3 (NO usar ^28 porque el runtime debe ser exacta)
- **Configuracion electron-builder:** `allowScripts: {"electron@28.3.3": true, "koffi@2.16.3": true}` - permite que electron-builder ejecute scripts postinstall

**`electron-builder`: ^25.1.8**
- **Que hace:** Empaqueta el proyecto Electron en un ejecutable .exe para Windows con instalador NSIS
- **Configuracion:** `asar: false` (NO empaquetar en asar - necesario para que los archivos .enc sean accesibles), `target: "nsis"`, `requestedExecutionLevel: "requireAdministrator"`

### Notas tecnicas importantes
- `asar: false` - NO empaquetar como asar (porque los .enc necesitan estar accesibles como archivos normales)
- `contextIsolation: true` - Seguridad: separa el renderer del main process
- `nodeIntegration: false` - Seguridad: no expone Node.js al renderer
- `sandbox: true` - Seguridad: ejecuta el renderer en entorno sandbox
- `requestedExecutionLevel: requireAdministrator` - Para inyeccion de DLLs se necesita admin
- `CSC_IDENTITY_AUTO_DISCOVERY = "false"` - No hay firma de codigo digital
- `CSC_LINK = ""` y `WIN_CSC_LINK = ""` - Sin certificado de firma
- `allowScripts: {"electron@28.3.3": true, "koffi@2.16.3": true}` - Koffi necesita compilar native modules

## 5. COMO CIFRAR UN DLL NUEVO (PASO A PASO)

### Requisitos previos
- Tener Node.js instalado
- Tener el archivo .dll que quieres cifrar
- Conocer la clave secreta: `RTX2026-GTA5-LAUNCHER-SECURE-ENCRYPT-KEY`

### Paso 1: Abre PowerShell en la carpeta donde esta el DLL
```powershell
cd C:\Users\Admin\Desktop\launcher\launcher
```

### Paso 2: Ejecuta este comando para cifrar el DLL
```powershell
node -e "const crypto=require('crypto'),fs=require('fs');const K=crypto.createHash('sha256').update('RTX2026-GTA5-LAUNCHER-SECURE-ENCRYPT-KEY').digest();const d=fs.readFileSync('TU_DLL.dll');const iv=crypto.randomBytes(16);const c=crypto.createCipheriv('aes-256-cbc',K,iv);let e=c.update(d);e=Buffer.concat([e,c.final()]);fs.writeFileSync('TU_DLL.enc',Buffer.concat([iv,e]));console.log('CIFRADO:',fs.statSync('TU_DLL.enc').size,'bytes');const v=fs.readFileSync('TU_DLL.enc');const di=v.slice(0,16),ct=v.slice(16);const dc=crypto.createDecipheriv('aes-256-cbc',K,di);let r=dc.update(ct);r=Buffer.concat([r,dc.final()]);console.log('VERIFICACION MZ:',r[0]===0x4D&&r[1]===0x5A);"
```

**Reemplaza `TU_DLL.dll` por el nombre del archivo DLL real.**

### Paso 3: Verifica el resultado
- Deberia ver `CIFRADO: X bytes`
- Deberia ver `VERIFICACION MZ: true` (significa que al desencriptar se obtiene un DLL valido con cabecera MZ)

### Paso 4: Renombra el archivo .enc resultante
- `YimMenuV2.dll` → `YimMenuV2.enc`
- Ponlo en `src/mods/GTA Enhanced/G MENU V2/YimMenuV2.enc`
- Crea el `mod.json` correspondiente

### Paso 5: Borra el DLL sin cifrar (IMPORTANTE)
```powershell
Remove-Item "TU_DLL.dll" -Force
```

### REGLAS IMPORTANTES DE ENCRIPTACION:
1. **NO agregar PKCS7 manual** - `cipher.final()` YA agrega padding PKCS7 automaticamente
2. Si agregas padding manual, se produce doble padding y el archivo NO se puede desencriptar (error BAD_DECRYPT)
3. El IV (16 bytes) se antepone al ciphertext - formato: `[iv(16)][ciphertext]`
4. Para verificar: el archivo .enc debe tener exactamente 16 bytes mas que el .dll original

## 6. COMO DESCIFRAR UN ARCHIVO .enc (PASO A PASO)

### El launcher hace esto automaticamente con `decryptFile()` en main.js:

```javascript
const crypto = require('crypto');

function decryptFile(encPath) {
  const data = fs.readFileSync(encPath);

  // Formato del archivo .enc: [iv(16 bytes)][ciphertext]
  const iv = data.slice(0, 16);
  const ct = data.slice(16);

  // Derivar clave desde passphrase
  const ENC_KEY = crypto.createHash('sha256').update('RTX2026-GTA5-LAUNCHER-SECURE-ENCRYPT-KEY').digest();

  // Desenciptar
  const decipher = crypto.createDecipheriv('aes-256-cbc', ENC_KEY, iv);
  decipher.setAutoPadding(false);
  let dec = Buffer.concat([decipher.update(ct), decipher.final()]);

  // Quitar padding PKCS7 (solo UNA vez)
  const padLen = dec[dec.length - 1];
  if (padLen > 0 && padLen <= 16) {
    dec = dec.slice(0, dec.length - padLen);
  }
  return dec;
}
```

### Para verificar manualmente:
```javascript
const crypto = require('crypto');
const fs = require('fs');
const ENC_KEY = crypto.createHash('sha256').update('RTX2026-GTA5-LAUNCHER-SECURE-ENCRYPT-KEY').digest();
const v = fs.readFileSync('archivo.enc');
const iv = v.slice(0, 16);
const ct = v.slice(16);
const decipher = crypto.createDecipheriv('aes-256-cbc', ENC_KEY, iv);
decipher.setAutoPadding(false);
let dec = Buffer.concat([decipher.update(ct), decipher.final()]);
const padLen = dec[dec.length - 1];
if (padLen > 0 && padLen <= 16) dec = dec.slice(0, dec.length - padLen);
console.log('MZ:', dec[0] === 0x4D && dec[1] === 0x5A);
console.log('Tamaño:', dec.length);
```

### ALGORITMO DE CIFRADO DETALLADO:
1. **Algoritmo:** AES-256-CBC (Advanced Encryption Standard, 256-bit key, Cipher Block Chaining)
2. **Clave:** SHA-256 hash de `'RTX2026-GTA5-LAUNCHER-SECURE-ENCRYPT-KEY'` (64 caracteres hex = 256 bits)
3. **IV (Initialization Vector):** 16 bytes aleatorios - diferente cada vez que se cifra
4. **Padding:** PKCS7 - el bloque se rellena para que sea multiplo de 16 bytes
5. **Formato archivo .enc:** `[IV(16 bytes)][CIPHERTEXT]`
6. **Por que AES-256-CBC:** Es el estandar de la industria para cifrado simetrico. Es lo que usa Windows para proteger datos sensibles.

### FORMATOS SOPORTADOS EN main.js:
- **v1 (legacy):** `[iv(16)][ciphertext]` con PKCS7 padding - USADO POR TODOS LOS MODS ACTUALES
- **v2 (nuevo):** `[version(1)=0x01][salt(16)][nonce(12)][tag(16)][ciphertext]` con AES-256-GCM - NO USADO TODAVIA

### Flujo de inyeccion
1. Usuario selecciona mod y GTA
2. `scanMods()` lee carpetas, busca archivos .enc + mod.json
3. `injectDLL(encPath, processId)`:
   a. `decryptFile(encPath)` → escribe DLL temporal
   b. `OpenProcess(PROCESS_ALL_ACCESS, false, pid)`
   c. `VirtualAllocEx` para la ruta DLL
   d. `WriteProcessMemory` con la ruta DLL
   e. `CreateRemoteThread` con `LoadLibraryW`
   f. `WaitForSingleObject` 5000ms
   g. `VirtualFreeEx`, `CloseHandle`
   h. `unlinkSync` del DLL temporal
   i. `app.quit()` despues de 1500ms
