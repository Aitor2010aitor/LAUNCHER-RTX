# RTX GTA V Launcher

Launcher de mods para GTA V con inyeccion de DLLs y actualizaciones automaticas.

## Descargas

Ve a [Releases](https://github.com/Aitor2010aitor/LAUNCHER-RTX/releases) para descargar la ultima version.

## Actualizaciones

El launcher busca actualizaciones automaticamente. Tambien puedes buscarlas manualmente desde la seccion "Actualizaciones".
