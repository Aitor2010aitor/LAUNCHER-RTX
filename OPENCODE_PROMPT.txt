## QUE HACE EL LAUNCHER (Resumen)

1. Detecta procesos de GTA V (GTA5.exe, GTA5_Enhanced.exe)
2. Lee mods encriptados (.enc) del directorio src/mods/
3. Desencripta .enc a .dll usando AES-256-CBC
4. Inyecta el DLL en GTA V via CreateRemoteThread + LoadLibraryW
5. Borra el DLL temporal
6. Cierra el launcher (app.quit() despues de 1500ms)
7. Auto-update desde GitHub Releases
8. Scripts: descarga .lua/.zip/.rar desde GitHub API
9. Inyeccion de DLL externa (file picker + injection)
10. UI tactica oscura/naranja con Electron

Encriptar DLL:
  node -e "const crypto=require('crypto'),fs=require('fs');const K=crypto.createHash('sha256').update('RTX2026-GTA5-LAUNCHER-SECURE-ENCRYPT-KEY').digest();const d=fs.readFileSync('archivo.dll');const iv=crypto.randomBytes(16);const c=crypto.createCipheriv('aes-256-cbc',K,iv);let e=c.update(d);e=Buffer.concat([e,c.final()]);fs.writeFileSync('archivo.enc',Buffer.concat([iv,e]));console.log('CIFRADO:',fs.statSync('archivo.enc').size,'bytes');"

Verificar desencriptacion:
  node -e "const crypto=require('crypto'),fs=require('fs');const K=crypto.createHash('sha256').update('RTX2026-GTA5-LAUNCHER-SECURE-ENCRYPT-KEY').digest();const v=fs.readFileSync('archivo.enc');const iv=v.slice(0,16),ct=v.slice(16);const dc=crypto.createDecipheriv('aes-256-cbc',K,iv);let r=dc.update(ct);r=Buffer.concat([r,dc.final()]);console.log('MZ:',r[0]===0x4D&&r[1]===0x5A,'Size:',r.length);"

Encriptar DLL (v2 GCM - formato preferido, si data[0]==1):
  node -e "const crypto=require('crypto'),fs=require('fs');const P='RTX2026-GTA5-LAUNCHER-SECURE-ENCRYPT-KEY';const d=fs.readFileSync('archivo.dll');const salt=crypto.randomBytes(16),nonce=crypto.randomBytes(12);const k=crypto.scryptSync(P,salt,32,{N:1<<14,r:8,p:1});const c=crypto.createCipheriv('aes-256-gcm',k,nonce);const ct=Buffer.concat([c.update(d),c.final()]);fs.writeFileSync('archivo.enc',Buffer.concat([Buffer.from([1]),salt,nonce,c.getAuthTag(),ct]));console.log('CIFRADO:',fs.statSync('archivo.enc').size,'bytes');"

Verificar desencriptacion v2 GCM:
  node -e "const crypto=require('crypto'),fs=require('fs');const P='RTX2026-GTA5-LAUNCHER-SECURE-ENCRYPT-KEY';const d=fs.readFileSync('archivo.enc');if(d[0]!==1){console.log('no es v2');process.exit(1)}const s=d.subarray(1,17),n=d.subarray(17,29),t=d.subarray(29,45),ct=d.subarray(45);const k=crypto.scryptSync(P,s,32,{N:1<<14,r:8,p:1});const dc=crypto.createDecipheriv('aes-256-gcm',k,n);dc.setAuthTag(t);const r=Buffer.concat([dc.update(ct),dc.final()]);console.log('MZ:',r[0]===0x4D&&r[1]===0x5A,'Size:',r.length);"
